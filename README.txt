KOMBI USTASI iOS V2

GitHub Pages / Netlify için hazır PWA.

Dosyaların tamamını repo içine yükle:
index.html
style.css
app.js
manifest.json
sw.js

Uygulama özellikleri:
- Çalışan aylık takvim ve günlük randevular
- Müşteri ekleme/düzenleme/silme
- Müşteri geçmişi
- Parça adı ve fiyatı ekleme
- Randevuya kayıtlı parçalardan seçim
- İşçilik + parça toplamı
- JSON yedek alma/geri yükleme
- Telefon ana ekranına uygulama olarak ekleme
- Veriler cihazda localStorage ile saklanır

ÖNEMLİ:
GitHub Pages kullanıyorsan repo kökünde bu dosyalar bulunmalı.
Eski dosyaları silip bunları yükleyebilirsin.
